## Tools

|Purpose|Tool|Why|
|---|---|---|
|Language|**Python 3.11+**|Simple, and the main language for AI work|
|IDE|**VS Code** + Python extension + GitHub Copilot|Free, and helps you code faster|
|Version control|**Git + GitHub**|Saves your progress and is needed for hackathons|
|Simulation and game screen|**Pygame**|Easy 2D graphics and handles real-time movement|
|Maths and data|**NumPy, Pandas**|Movement calculations and data tables|
|AI classifier|**scikit-learn** (Random Forest)|Beginner-friendly and accurate on this kind of data|
|Saving the model|**joblib**|Lets the trained model be loaded into the simulator|
|Dashboard|**Streamlit + Plotly**|A web dashboard written in pure Python|
|Session data|**CSV / JSON files**|The simple "bridge" between the simulator and the dashboard|
|Add-ons|OpenAI/Azure API (instructor), Stable-Baselines3 (smart drone)|Only if time permits|
